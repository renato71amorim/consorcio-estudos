# Assets

Pasta destinada a arquivos de apoio:

- PDFs de referência (listas oficiais, cartilhas)
- Diagramas e fluxogramas (jornada do cliente, funil de conteúdo)
- Imagens de tabelas e comparativos
- Capturas de tela de landing pages (com data e fonte)

## Padrão de nomenclatura

```
AAAA-MM-DD-descricao-curta.ext
```

Exemplo: `2026-10-30-lista-parceiros-bb.pdf`

## Aviso

Não inclua arquivos com dados sensíveis (contratos pessoais, comissões negociadas, dados de clientes).
